**AutoModel Insight** is an AI-powered web application built with the **MERN stack** and **Flask**, designed to identify the make, model, and variant of a car from an uploaded image. It uses a **Convolutional Neural Network (CNN)** trained on a custom dataset, achieving an impressive **92% accuracy** in car recognition. The deep learning model was developed using **TensorFlow** and **Keras** and integrated with Flask for smooth API communication. The frontend is built with **React.js**, and **MongoDB** is used for secure and efficient data management. This project highlights strong expertise in **computer vision**, **deep learning**, and **full-stack AI integration**.
